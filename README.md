# Tenant Turner Demo frame archive

This branch contains the 12 verified archive parts for all 20,565 frames of the Tenant Turner screen share. Each archive holds numbered 2304 × 1440 JPEGs at 30 fps. Selected contact details, ID imagery and access credentials are masked.

See the [archive guide](../main/archive.md) for the frame ranges, download instructions and index, or open the [walkthrough](../main/walkthrough.md) for the annotated demo.
